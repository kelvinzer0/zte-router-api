💡 Catatan Penting Mengenai Telnet ZTE:

              
    
                
  • LAN vs WAN: Router ZTE secara default memblokir port 23 dari antarmuka WAN. Jika router diakses melalui IP WAN (misal 10.200.204.1), port 23 akan menolak koneksi. Sambungkan komputer langsung ke port LAN atau WiFi router (biasanya 192.168.1.1) untuk koneksi Telnet tanpa batasan firewall.
    • 
                
  • Factory Mode: Tombol Aktifkan Telnet via Factory Mode akan memicu endpoint internal /webFac router untuk membuka port telnet dan menghasilkan kredensial sementara.
